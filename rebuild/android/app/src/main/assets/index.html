Банковские уведомления

Доступ к уведомлениям Проверяем…

Доступ выдаётся в настройках Android. Приложение сохраняет только сообщения об операциях из известных банковских приложений, не читает переписки и не отправляет данные в интернет.

Требуют проверки

Сообщения не влияют на остатки, пока вы не создадите операцию вручную. При повторном получении одинакового события оно не создаёт вторую операцию.
