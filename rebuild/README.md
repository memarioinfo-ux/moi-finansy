# Мои финансы — новая разработка (rebuild-v2)

Этот каталог — **новая разработка**, а не очередной патч старого `index.html`.

> **Не устанавливать сборки поверх приложения v1.0.6.4 до подтверждённой резервной копии и проверки идентификатора пакета/подписи.** Существующие ветки `main` и `stable-v18` не изменяются.

## Что проверено по старой версии
- Основной `index.html` (~420 КБ, 7 828 строк) совмещает интерфейс, бизнес-логику и сохранение данных.
- Счета, операции и категории сериализуются в `localStorage['alina_budget_state_v10']`.
- Необработанные push дополнительно сохраняются в `localStorage['alina_unrecognized_bank_pushes']`, но очередь ограничивается последними 20 записями.
- Отдельные native Android-части и подпись APK требуют независимой проверки.
- Ветка `main` уже содержит незавершённую интеграцию InSync версии v19; она не считается стабильным релизом.

## Новая структура
- `core/ledger.mjs` — независимая от UI логика операций, счетов, балансов, неизменяемого журнала сырых уведомлений и проверки резервных копий.
- `test/ledger.test.mjs` — автотесты основных инвариантов.
- `docs/architecture.md` — архитектура Android-приложения, перенос данных и этапы.
- `android/` — автономный Android-проект Kotlin/Room с локальным интерфейсом WebView, ручным учётом и архивами.
- `android/app/src/main/java/by/moifinansy/rebuild/BankNotificationListener.kt` — изолированный журнал поддерживаемых банковских уведомлений после разрешения Android.
- `android/README.md` — ограничения, правила установки, приёмочные сценарии.

## Запуск тестов
Node.js 20 или новее:
```bash
node --test rebuild/test/ledger.test.mjs
```

## Состояние
**Этапы 0–2:** создано финансовое ядро и отдельный Android-проект. Отдельный APK первой версии успешно собирался в GitHub Actions; реализованы офлайн-счета, операции, переводы, аналитика, история и ручные резервные копии. Сборки последних изменений ещё требуют повторной проверки, автоматический CI выключен по просьбе владельца.

**Этап 3 — в разработке:** добавлен фильтруемый Android NotificationListenerService для известного набора банковских пакетов и экран ручного разбора; запись операции и пометка исходного события выполняются в транзакции базы. Не проверено на реальном телефоне; поддержка SMS Mbank из приложений сообщений и автоматическая классификация отсутствуют.

**Старые данные:** установленную v1.0.6.4 нельзя заменять или удалять. История с Samsung пока не перенесена. Новая версия устанавливается отдельно; debug-подпись GitHub может меняться между сборками.
