# Мои финансы — новая разработка (rebuild-v2)

Этот каталог — **новая разработка**, а не очередной патч старого `index.html`.

> **Не устанавливать сборки поверх приложения v1.0.6.4 до подтверждённой резервной копии и проверки идентификатора пакета/подписи.** Существующие ветки `main` и `stable-v18` не изменяются.

## Что проверено по старой версии
- Основной `index.html` (~420 КБ, 7 828 строк) совмещает интерфейс, бизнес-логику и сохранение данных.
- Счета, операции и категории сериализуются в `localStorage['alina_budget_state_v10']`.
- Необработанные push дополнительно сохраняются в `localStorage['alina_unrecognized_bank_pushes']`, но очередь ограничивается последними 20 записями.
- Отдельные native Android-части и подпись APK требуют независимой проверки.
- Ветка `main` уже содержит незавершённую интеграцию InSync версии v19; она не считается стабильным релизом.

## Новая структура
- `core/ledger.mjs` — независимая от UI логика операций, счетов, балансов, неизменяемого журнала сырых уведомлений и проверки резервных копий.
- `test/ledger.test.mjs` — автотесты основных инвариантов.
- `docs/architecture.md` — архитектура Android-приложения, перенос данных и этапы.

## Запуск тестов
Node.js 20 или новее:
```bash
node --test rebuild/test/ledger.test.mjs
```

## Состояние
Начат **этап 0**: аудит старого приложения, изоляция нового проекта и базовая финансовая логика. Ветка не содержит готового APK, UI или реально работающего чтения банковских push. Эти функции требуют следующего этапа разработки и тестирования на Android.
